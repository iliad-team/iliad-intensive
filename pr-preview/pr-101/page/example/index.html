  • Group outcomes with \subsection*{...} plus an itemize when a flat list gets long.

This dummy worksheet demonstrates every construct that survives the round trip from LaTeX to the curriculum website. Compile it with pdflatex (twice, then bibtex, then twice again for the bibliography), or just read the source side by side with the rendered page.

1. Prerequisites

Prerequisites, further reading, and anything else you want to say are just ordinary LaTeX — no special markup. For this sheet:

  • comfort with probability on finite sets (E\EE, distributions);
  • one variable of calculus (we differentiate −tlog⁡t-t \log t−tlogt once).

2. Prose, math, and cross-references

Ordinary prose converts verbatim, including emphasis, bold, monospace, and special characters like 50% or §3. Inline math is copied byte-for-byte: eiπ+1=0e^{i\pi}+ 1 = 0eiπ+1=0, and KaTeX handles comparisons like x<tx_{<t}x<t​ without trouble. 3. Definitions, theorems, and callouts

Label anything you want to reference. Any placement LaTeX binds correctly is valid (top level of the environment); right after the begin is clearest.

Definition 3.1 (entropy). The entropy of a distribution ppp on a finite set X\mathcal{X}X is

H(p)=−∑x∈Xp(x)log⁡p(x).H(p) = -\sum_{x \in \mathcal{X}}p(x) \log p(x).H(p)=−x∈X∑​p(x)logp(x).

Theorem 3.2 (Gibbs' inequality). For any distributions p,qp, qp,q on X\mathcal{X}X, −∑xp(x)log⁡q(x)≥H(p)-\sum_{x} p(x) \log q(x) \geq H(p)−∑x​p(x)logq(x)≥H(p), with equality iff p=qp = qp=q.

Proof

By definition, DKL ⁣(p ∥ q)=∑xp(x)log⁡p(x)q(x)≥0\KL{p}{q}= \sum_{x} p(x) \log \frac{p(x)}{q(x)}\geq 0DKL​(p∥q)=∑x​p(x)logq(x)p(x)​≥0 by Jensen's inequality applied to the concave function log⁡\loglog; rearranging gives the claim. 4. Exercises and solutions

The optional argument of an exercise is its title, exactly as in amsthm. An optional \important mark (a ★\bigstar★ flagging the sheet's most important exercises) goes right after the label. Subparts are a plain enumerate; label an item to reference it. Every solution names its exercise — [ex:label] is mandatory — so you may place solutions right after each exercise or collect them at the end, as you prefer. Exercises don't require solutions; label any exercise a solution or reference points at.
