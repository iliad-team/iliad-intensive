Training Dynamics

Cluster BB.4 · Training Dynamics

Exact learning dynamics of deep linear networks -- loss-landscape geometry, balanced gradient flow and the NTK, the rich (saddle-to-saddle) and lazy regimes, their mixed unification, and the implicit bias of SGD noise.

By Guillaume Corlouer (Stormglass)

1. Setup and notation

We study deep linear networks (DLNs) with L weight matrices W1​∈Rd1​×d0​,W2​∈Rd2​×d1​,…,WL​∈RdL​×dL−1​. The network computes:

f(x)=WL​WL−1​⋯W1​x=:Wx

where W=WL​⋯W1​∈RdL​×d0​ is the end-to-end (or "student") matrix. We train on a dataset {(xμ​,yμ​)}μ=1N​ with the squared loss:

L(θ)=2N1​μ=1∑N​∥yμ​−f(xμ​)∥2

In the population limit N→∞ with whitened inputs ΣX​=I, this becomes, up to an additive constant1:

L(W)=21​∥M−W∥F2​

where M=ΣYX​ΣX−1​=ΣYX​ is the "teacher" matrix (the OLS solution) with SVD M=Udiag(s1​,…,sr​,0,…,0)V⊤, and s1​≥s2​≥⋯≥sr​>0.

2. Loss landscape geometry

This problem explores the critical point structure of deep linear networks, following (Achour et al. 2024).

Exercise 2.1 (Diagonal decomposition). Consider the diagonal case: d0​=d1​=⋯=dL​=d, and the teacher is diagonal, M=diag(s1​,…,sd​), with s1​>s2​>⋯>sd​>0. Restrict attention to diagonal weight matrices Wl​=diag(wl(1)​,…,wl(d)​). Show that the loss decomposes into d independent scalar problems:

L=21​α=1∑d​(sα​−l=1∏L​wl(α)​)2
Solution

When all Wl​ are diagonal, the product W=WL​⋯W1​ is also diagonal with entries (W)αα​=∏l=1L​wl(α)​. The teacher M is diagonal with entries sα​. Then:

L=21​∥M−W∥F2​=21​α=1∑d​(sα​−(W)αα​)2=21​α=1∑d​(sα​−l=1∏L​wl(α)​)2

Since the different modes α share no parameters, the loss decomposes into d independent scalar problems. □

Exercise 2.2 (Scalar critical points). For a single scalar mode with target s>0, find all first-order critical points of ℓ(w1​,w2​)=21​(s−w1​w2​)2 at depth L=2. Show that the critical points are:

  • The global minimum manifold: w1​w2​=s
  • The origin: w1​=w2​=0

Classify the origin as a saddle point by computing the Hessian H of ℓ at (0,0) and showing it has both positive and negative eigenvalues.

Hint: Write the gradient equations.

Solution

For L=2, the gradient equations are:

∂w1​∂ℓ​=−(s−w1​w2​)w2​=0,∂w2​∂ℓ​=−(s−w1​w2​)w1​=0

Case 1: s−w1​w2​=0, i.e. w1​w2​=s. This is the global minimum manifold (a hyperbola w2​=s/w1​) with ℓ=0.

Case 2: If s−w1​w2​=0, then the first equation requires w2​=0 and the second requires w1​=0. (For instance, if w2​=0 and w1​=0, the first equation gives −sw2​=0, which contradicts s>0 and w2​=0.) So the only other critical point is w1​=w2​=0.

The Hessian at (0,0). We need the second derivatives of ℓ=21​(s−w1​w2​)2:

∂w12​∂2ℓ​∂w1​∂w2​∂2ℓ​​=w22​,∂w22​∂2ℓ​=w12​,=−(s−w1​w2​)+w1​w2​=2w1​w2​−s​

At (0,0):

H=(0−s​−s0​)

The eigenvalues are ±s. Since s>0, H has one positive and one negative eigenvalue. The origin is a strict saddle point. □

Exercise 2.3 (Critical-point structure). Achour et al. (Achour et al. 2024) show that every first-order critical point θ=(W1​,…,WL​) satisfies: there exists a subset S⊆{1,…,d} such that

W=WL​⋯W1​=PS​M

where PS​=US​US⊤​ is the orthogonal projector onto the span of the left singular vectors {uα​}α∈S​ of M. For the diagonal case M=diag(s1​,…,sd​), write the value of the loss at the critical point corresponding to S={1,…,r} with r<d.

Solution

At the critical point W=PS​M with S={1,…,r}, the student retains only the first r modes: W=diag(s1​,…,sr​,0,…,0). The loss is:

L=21​∥M−PS​M∥F2​=21​α∈/S∑​sα2​=21​α=r+1∑d​sα2​

This is strictly positive whenever r<d (since all sα​>0), so these are not global minima. By the Hessian analysis (extending Exercise 2.2), the direction corresponding to "switching on" a missing mode α∈/S is a descent direction, making these critical points saddle points. All critical points with ∣S∣=d have W=M and L=0: these are the global minima. Therefore there are no spurious local minima — every local minimum is global. □

Exercise 2.4 (Symmetry of the global minima). The group GLh​:=GLd1​​×⋯×GLdL−1​​ acts on the weights by:

(W1​,…,WL​)↦(g1​W1​,g2​W2​g1−1​,…,WL​gL−1−1​)

Verify that the student map μ(θ)=WL​⋯W1​ is invariant under this action: μ(g⋅θ)=μ(θ).

Solution

Under the group action:

μ(g⋅θ)=WL​gL−1−1​⋅gL−1​WL−1​gL−2−1​⋅…⋅g1​W1​=WL​WL−1​⋯W1​=μ(θ)

All gl​ and gl−1​ factors cancel telescopically. This means every parameter point in the orbit Oθ​=GLh​⋅θ maps to the same student W. □

For the dimension of the set of global minima, this invariance means the following. The global minima form the fiber μ−1(M), which contains the entire orbit GLh​⋅θ∗ for any global minimizer θ∗. The orbit has dimension ∑l=1L−1​dl2​ (the dimension of GLh​), so the set of global minima is a continuous manifold of very high dimension — far from being isolated points. □

3. Gradient flow and conserved quantities

We now study gradient flow: θ˙(t)=−∇θ​L(θ(t)), the continuous-time limit of gradient descent with infinitesimal learning rate.

Exercise 3.1 (Gradient-flow equations). For a two-layer DLN (L=2), the loss is given by L=21​∥M−W2​W1​∥F2​. Assume that each weight matrix Wi​ is diagonal. Derive the gradient flow equations for each layer. In particular, show that:

W˙1​=W2⊤​(M−W2​W1​),W˙2​=(M−W2​W1​)W1⊤​

Note: these equations also hold for general (non-diagonal) W1​ and W2​.

Solution

We have L=21​∥M−W2​W1​∥F2​=21​Tr[(M−W2​W1​)⊤(M−W2​W1​)].

General matrix derivation. Expand:

L=21​Tr(M⊤M)−Tr(M⊤W2​W1​)+21​Tr(W1⊤​W2⊤​W2​W1​)

Differentiating with respect to W1​, using ∂A∂​Tr(B⊤A)=B and ∂A∂​Tr(A⊤CA)=(C+C⊤)A:

∇W1​​L=−W2⊤​M+W2⊤​W2​W1​=−W2⊤​(M−W2​W1​)

So W˙1​=−∇W1​​L=W2⊤​(M−W2​W1​).

Similarly, ∇W2​​L=−(M−W2​W1​)W1⊤​, giving W˙2​=(M−W2​W1​)W1⊤​.

Diagonal shortcut. For diagonal matrices W1​=diag(aα​), W2​=diag(bα​), M=diag(sα​): the loss decouples as L=21​∑α​(sα​−bα​aα​)2. Then a˙α​=−∂L/∂aα​=bα​(sα​−bα​aα​) and b˙α​=aα​(sα​−bα​aα​), which is the diagonal version of the matrix equations above. □

Exercise 3.2 (Balancedness is conserved). Define the balancedness matrix:

G:=W2⊤​W2​−W1​W1⊤​

Show that G is conserved under the gradient flow, i.e. G˙=0. In other words, gradient flow is constrained to the balanced manifold

Mβ​:={θ∈Ω∣Wℓ+1⊤​Wℓ+1​−Wℓ​Wℓ⊤​=βℓ​,ℓ=1,…,L−1}.

Hint: Compute G˙, substitute the gradient flow equations and verify that the terms cancel pairwise.

Solution

Let E:=M−W2​W1​ denote the residual. Compute:

G˙=W˙2⊤​W2​+W2⊤​W˙2​−W˙1​W1⊤​−W1​W˙1⊤​

Substitute the gradient flow equations. Using W˙2​=EW1⊤​ and W˙1​=W2⊤​E:

W˙2⊤​W2​=(EW1⊤​)⊤W2​=W1​E⊤W2​W2⊤​W˙2​=W2⊤​EW1⊤​W˙1​W1⊤​=W2⊤​EW1⊤​W1​W˙1⊤​=W1​(W2⊤​E)⊤=W1​E⊤W2​

Therefore:

G˙=W1​E⊤W2​+W2⊤​EW1⊤​−W2⊤​EW1⊤​−W1​E⊤W2​=0

The terms cancel pairwise. G is conserved. □

From now on, assume balanced initialization: G(0)=0, which by Exercise 3.2 means W2⊤​W2​=W1​W1⊤​ for all time. We want to derive the gradient flow in function space (the ODE for the student W=W2​W1​). This requires several steps.

Exercise 3.3 (Function-space velocity). Compute W˙:=dtd​(W2​W1​) using the gradient flow equations from Exercise 3.1. Show that:

W˙=(M−W)W1⊤​W1​+W2​W2⊤​(M−W)
Solution

Apply the product rule:

W˙=W˙2​W1​+W2​W˙1​=(M−W2​W1​)W1⊤​⋅W1​+W2​⋅W2⊤​(M−W2​W1​)

Writing W=W2​W1​:

W˙=(M−W)W1⊤​W1​+W2​W2⊤​(M−W)□

Exercise 3.4 (W1⊤​W1​ in terms of W). We now need to express W1⊤​W1​ and W2​W2⊤​ in terms of W=W2​W1​. Show that:

W1⊤​W1​=(W⊤W)1/2
Solution

Balancedness gives W2⊤​W2​=W1​W1⊤​, so

W⊤W=W1⊤​(W2⊤​W2​)W1​=W1⊤​(W1​W1⊤​)W1​=(W1⊤​W1​)2

Both W⊤W and W1⊤​W1​ are positive semidefinite. A positive semidefinite matrix has a unique positive semidefinite square root, so it follows that

(W⊤W)1/2=W1⊤​W1​□

Exercise 3.5 (W2​W2⊤​ in terms of W). Similarly, show that W2​W2⊤​=(WW⊤)1/2.

Solution

Analogous to Exercise 3.4.

Exercise 3.6 (The balanced function-space ODE). Substitute the results of Exercise 3.4 and 3.5 into Exercise 3.3 to obtain:

W˙=(WW⊤)1/2(M−W)+(M−W)(W⊤W)1/2
Solution

Substituting into Exercise 3.3:

W˙=(M−W)(W⊤W)1/2+(WW⊤)1/2(M−W)□

Exercise 3.7 (The NTK operator). Define the NTK operator for L=2 as:

K[F]:=(WW⊤)1/2F+F(W⊤W)1/2

Show that the gradient flow from Exercise 3.6 can be written as W˙=K[M−W].

It turns out that this result generalizes to depth L on the balanced manifold:

W˙=k=1∑L​(WW⊤)LL−k​(M−W)(W⊤W)Lk−1​

This is the NTK equation in the case of DLNs. The NTK equation is a gradient flow in function space with NTK being a preconditioning operator for the gradient.

Solution

With F=M−W, the equation from Exercise 3.6 reads:

W˙=(WW⊤)1/2F+F(W⊤W)1/2=K[F]=K[M−W]□

The general depth-L result W˙=∑k=1L​(WW⊤)(L−k)/L(M−W)(W⊤W)(k−1)/L follows from the same approach applied to the L-fold balanced conditions Wl+1⊤​Wl+1​=Wl​Wl⊤​ for all l.

4. Rich regime: saddle-to-saddle

This is the core problem. We derive the exact solution of the rich regime dynamics directly from the self-consistent equation of Section 3, emphasizing the NTK perspective.

Alignment assumption. Start from the balanced gradient flow equation derived in Exercise 3.6:

W˙=(WW⊤)1/2(M−W)+(M−W)(W⊤W)1/2

We work in the rich regime (small initialization) with balanced weights. Assume that the student is aligned to the teacher: the singular vectors of W(t) coincide with those of M at all times. Concretely, write:

M=Udiag(s1​,…,sd​)V⊤,W(t)=Udiag(w1​(t),…,wd​(t))V⊤

where U,V are the left/right singular vectors of M, and wα​(t)≥0 are the evolving singular values of W.

Exercise 4.1 (Aligned NTK). Under this alignment assumption, show that the NTK operator is aligned to the task, i.e. K[F] preserves the SVD basis. In particular, show that:

(WW⊤)1/2(W⊤W)1/2​=Udiag(w1​,…,wd​)U⊤,=Vdiag(w1​,…,wd​)V⊤​

and that the residual is M−W=Udiag(s1​−w1​,…,sd​−wd​)V⊤.

Hint: Recall that for A=Udiag(σi​)V⊤, we have AA⊤=Udiag(σi2​)U⊤, and therefore (AA⊤)1/2=Udiag(∣σi​∣)U⊤.

Solution

Under the alignment assumption, W=Udiag(wα​)V⊤. Then:

WW⊤=Udiag(wα2​)U⊤

Since wα​≥0, the positive matrix square root is:

(WW⊤)1/2=Udiag(wα​)U⊤

Similarly:

W⊤W=Vdiag(wα2​)V⊤⟹(W⊤W)1/2=Vdiag(wα​)V⊤

The residual is immediate:

M−W=Udiag(sα​−wα​)V⊤

The NTK operator acts on any matrix F=Udiag(fα​)V⊤ as:

K[F]​=Udiag(wα​)U⊤Udiag(fα​)V⊤+Udiag(fα​)V⊤Vdiag(wα​)V⊤=Udiag(2wα​fα​)V⊤.​

So K[F] stays in the SVD basis of M — the NTK is aligned to the task. □

Exercise 4.2 (Decoupled scalar ODEs). Substitute into the self-consistent equation. Show that the matrix equation decouples into d independent scalar ODEs:

w˙α​=2wα​(sα​−wα​),α=1,…,d

Hint: Compute the product (WW⊤)1/2(M−W) in the SVD basis. It is diagonal with entries wα​(sα​−wα​). The second term contributes identically, giving the factor of 2.

Solution

Substitute into W˙=(WW⊤)1/2(M−W)+(M−W)(W⊤W)1/2:

First term:

Udiag(wα​)IU⊤U​​diag(sα​−wα​)V⊤=Udiag(wα​(sα​−wα​))V⊤

Second term:

Udiag(sα​−wα​)IV⊤V​​diag(wα​)V⊤=Udiag((sα​−wα​)wα​)V⊤

Summing:

W˙=Udiag(2wα​(sα​−wα​))V⊤

Since W=Udiag(wα​)V⊤ and the singular vectors are constant by assumption, we read off:

w˙α​=2wα​(sα​−wα​)​

The NTK perspective makes the structure transparent: the factor 2wα​ is the NTK eigenvalue for mode α, which amplifies learning in directions that are already strong, while (sα​−wα​) is the residual. □

Exercise 4.3 (Timescale of learning). The ODE w˙=2w(s−w) is a logistic equation whose solution is:

w(t)=1+(w0​s​−1)e−2sts​

where w0​=w(0). Compute the time tα​ it takes for mode α to travel from initial strength w0​ to a final strength wf​. Show that:

tα​=2sα​1​ln(w0​(sα​−wf​)wf​(sα​−w0​)​)

Deduce that modes with larger singular values sα​ are learned faster. This is a separation of timescales: the network learns features in decreasing order of their singular value strength.

Solution

From the logistic solution w(t)=1+(s/w0​−1)e−2sts​, we invert to find t as a function of w. The derivation is equivalent to integrating w˙=2w(s−w) by separation of variables:

∫w0​wf​​w(s−w)dw​=2tα​

Using partial fractions w(s−w)1​=s1​(w1​+s−w1​):

sα​1​[lnw−ln(sα​−w)]w0​wf​​=2tα​sα​1​lnw0​(sα​−wf​)wf​(sα​−w0​)​=2tα​

Therefore:

tα​=2sα​1​ln(w0​(sα​−wf​)wf​(sα​−w0​)​)​

For a fixed ratio wf​/sα​ and fixed w0​, the learning time scales as tα​∝1/sα​: modes with larger singular values are learned faster. The network learns features in decreasing order of their strength — a strong separation of timescales.

Contrast with the lazy regime (anticipating Section 5): in the lazy regime the NTK is frozen at K0​=2w0​≫1, so w˙α​≈2w0​(sα​−wα​). All modes converge at the same exponential rate 2w0​, independent of sα​. The rich regime has state-dependent NTK (2wα​), creating a positive feedback loop — modes that are already large learn even faster — which amplifies the differences between sα​ into a hierarchy of timescales t1​≪t2​≪⋯≪tr​. □

Exercise 4.4 (Incremental learning). Consider a teacher with r nonzero singular values and a small uniform initialization wα​(0)=w0​≪sr​ for all α. Qualitatively, discuss:

  • What is the approximate distribution of singular values of W(t) at early times?
  • How do the singular values of W(t) evolve throughout training?
  • What happens in the limit t→∞?

What does this analysis tell us about the sequence of critical points visited by the gradient flow?

Solution

With uniform initialization wα​(0)=w0​ for all α, the sigmoid solution shows that mode α remains near w0​ until time t≈2sα​1​ln(sα​/w0​), then transitions rapidly to wα​≈sα​.

Early times (t∼2s1​1​ln(s1​/w0​)): Only mode 1 has grown significantly, so the spectrum is one singular value near s1​, with all the others still near w0​≪sr​. The student is approximately W(t)≈w1​(t)u1​v1⊤​, effectively rank 1.

Intermediate times: As t increases, w2​ switches on, then w3​, etc. The singular values switch on one at a time, in decreasing order of sα​, each staying near w0​ and then rising to sα​ over a narrow window. The student is approximately W(t)≈∑α=1k(t)​wα​(t)uα​vα⊤​ where k(t) increases stepwise, so the effective rank increases incrementally.

Long times (t→∞): All modes converge, wα​→sα​, and W→M.

This is an implicit bias toward low-rank (simple) solutions: at any finite time, the network represents the best rank-k approximation to the teacher. The gradient flow effectively performs a greedy SVD.

Connection to the saddle structure (Exercise 2.3): The saddle points PS​M with ∣S∣=k are exactly the best rank-k approximations to M, with loss 21​∑α>k​sα2​. The gradient flow trajectory passes near these saddles as it incrementally recruits modes. The plateaus in the loss curve correspond to time spent near saddle points (only k modes active), and the sharp transitions correspond to escaping along the unstable direction that activates the next mode. □

5. Lazy regime

We now show that large initialization freezes the NTK and eliminates the timescale separation found in Section 4. For clarity, we work with the diagonal scalar model from Exercise 2.1, so each mode α is independent. This avoids matrix algebra and isolates the essential mechanism.

Setup. Consider a single mode: a depth-2 diagonal DLN with scalar weights a,b learning a target s>0. From Section 3 and 4, the balanced gradient flow for w=ab is:

w˙=2w(s−w)

The factor 2w is the (scalar) NTK — it is state-dependent: the effective learning rate depends on the current value of w.

Exercise 5.1 (Linearizing the NTK). Now initialize at a large value w0​≫s>0. Assume that in the early phase of training, while w has not changed much from w0​, the ODE becomes approximately:

w˙≈2w0​(s−w)
Solution

Starting from the same ODE w˙=2w(s−w), with w0​≫s>0, the weight w needs to decrease from w0​ to s. As long as w has not changed much from w0​, we can write w=w0​+δw with ∣δw∣≪w0​, so:

2w=2(w0​+δw)≈2w0​

The ODE becomes:

w˙≈2w0​(s−w)□

This is a linear ODE — the NTK factor 2w has been frozen at its initial value 2w0​. Note that only the NTK prefactor is linearized; the residual (s−w) is kept exact since it drives learning.

Exercise 5.2 (Frozen-NTK solution). Solve the linearized ODE from Exercise 5.1. Show that:

w(t)=s+(w0​−s)e−2w0​t

What is the learning timescale?

Solution

The linearized ODE w˙=2w0​(s−w) is first-order linear. Set w~:=w−s, then w~˙=−2w0​w~, with solution w~(t)=(w0​−s)e−2w0​t. Therefore:

w(t)=s+(w0​−s)e−2w0​t​

This is exponential convergence to s (contrast with the sigmoid of Section 4). The learning timescale is:

tlazy​∼2w0​1​

It depends on the initialization scale w0​ but not on the target s. This is the defining feature of the lazy regime: the learning speed is set by the NTK at initialization, not by the structure of the task.

Self-consistency: During the learning phase (t≲1/(2w0​)), the displacement is ∣w(t)−w0​∣≤∣s−w0​∣≈w0​ (since w0​≫s). The relative change in the NTK is Δ(2w)/(2w0​)=(w0​−s)/w0​=1−s/w0​≈1, so the NTK does change significantly in absolute terms. However, the key point is that the dynamics remain well approximated by the linear ODE because the convergence rate is dominated by 2w0​, which is large and approximately constant throughout training. In the rich regime, by contrast, the NTK changes from 2w0​≈0 to 2s — a change of order s/w0​→∞ relative to the initial value — making the linearization completely invalid. □

Exercise 5.3 (No timescale separation). Now restore the mode index α. In the lazy regime, each mode satisfies w˙α​≈2w0​(sα​−wα​) with the same rate 2w0​ for all α. Compare the lazy learning time tαlazy​ with the rich-regime timescale from Exercise 4.3: tαrich​∝1/sα​.

Solution

Restoring the mode index, each mode satisfies w˙α​≈2w0​(sα​−wα​) with solution:

wα​(t)=sα​+(w0​−sα​)e−2w0​t

All modes converge at the same exponential rate 2w0​, regardless of sα​. The time for mode α to go from w0​ to within (1−ϵ) of sα​ is:

tαlazy​=2w0​1​ln(ϵ(w0​−sα​)w0​−sα​​)=2w0​1​lnϵ1​

which is independent of sα​. All modes reach their targets simultaneously.

Contrast with the rich regime:

Rich regimeLazy regime
NTKState-dependent: 2wα​Frozen: 2w0​
Learning time for mode αtα​∝1/sα​tα​≈const
Timescale separationStrong: t1​≪t2​≪⋯None
Intermediate solutionsLow-rank (incremental)Full-rank from the start
Implicit rank biasYes (low-rank → high-rank)No

In the lazy regime, all components of M are learned simultaneously: signal and noise alike. The network converges directly to the full OLS solution without passing through low-rank intermediates. There is no mechanism to separate signal from noise based on singular value structure. With early stopping, the rich regime recovers a low-rank signal while ignoring noise; the lazy regime cannot. □

6. Mixed dynamics: unifying lazy and rich

In practice, networks are neither purely lazy nor purely rich. Tu, Aranguri & Jacot (2024) provide a unified description. We develop the key ideas using the diagonal scalar model.

Exercise 6.1 (The interpolating ODE). In Section 4 and 5, we studied the same ODE w˙α​=2wα​(sα​−wα​) in two limits: small w0​ (rich) and large w0​ (lazy). A more general model for a depth-2 DLN with balanced initialization at scale σ and width n replaces the scalar NTK 2wα​ by:

w˙α​=2wα2​+τ2​(sα​−wα​)

where τ:=σ2n​ is a threshold parameter that depends on the initialization scale and width.

Verify that this ODE reproduces the two known regimes:

  • Rich limit (τ→0): recover w˙α​=2∣wα​∣(sα​−wα​).
  • Lazy limit (τ→∞ with wα​ bounded): recover w˙α​≈2τ(sα​−wα​).
Solution

The interpolating ODE is w˙α​=2wα2​+τ2​(sα​−wα​).

Rich limit (τ→0): The square root reduces to wα2​​=∣wα​∣, giving:

w˙α​=2∣wα​∣(sα​−wα​)

For wα​>0 this is 2wα​(sα​−wα​), exactly the logistic ODE from Exercise 4.2. □

Lazy limit (τ→∞, wα​ bounded): The square root is dominated by τ: wα2​+τ2​≈τ, giving:

w˙α​≈2τ(sα​−wα​)

This is a linear ODE with rate 2τ, independent of sα​ — the frozen-NTK regime of Section 5 (with τ playing the role of w0​). □

Exercise 6.2 (Two-phase dynamics). At initialization, all modes start at wα​(0)∼σ2≪τ (since n​≫1). Observe that:

  • When ∣wα​∣≪τ, the effective learning rate is ≈2τ, the same for all modes (lazy behavior).
  • When ∣wα​∣≫τ, the effective learning rate is ≈2∣wα​∣, which is mode-dependent (rich behavior).

Describe the resulting two-phase dynamics in words: what happens first, and what happens later?

Solution

At initialization, wα​(0)∼σ2≪τ=σ2n​ (since n​≫1). So initially all modes satisfy ∣wα​∣≪τ.

Early phase (lazy): wα2​+τ2​≈τ for all α. Every mode evolves at the same linear rate 2τ:

w˙α​≈2τ(sα​−wα​)⟹wα​(t)≈sα​(1−e−2τt)

(assuming wα​(0)≈0). The dynamics are approximately linear and the NTK is approximately constant. During this phase, the network aligns with the task: each wα​ grows toward sα​ at the same rate. There is no timescale separation.

Late phase (rich): Once some wα​ grow past τ, the square root transitions to wα2​+τ2​≈∣wα​∣, and those modes enter the rich regime with the sigmoidal, self-accelerating dynamics w˙α​≈2wα​(sα​−wα​). The state-dependent NTK creates timescale separation, and the modes that have crossed the threshold converge rapidly to their targets.

In summary: the network starts in a lazy phase where all modes grow uniformly (alignment), then transitions to a rich phase where modes accelerate individually (incremental learning). □

Exercise 6.3 (Mode-by-mode transition). Not all modes cross the threshold τ at the same time: which modes cross it first? Explain why this means that a single network can simultaneously have some modes in the rich regime and others still in the lazy regime.

Solution

In the lazy phase, each mode grows as wα​(t)≈sα​(1−e−2τt). At any given time, wα​(t)∝sα​: modes with larger sα​ are larger. Since the lazy-to-rich transition occurs when ∣wα​∣∼τ, the time for mode α to cross the threshold satisfies:

sα​(1−e−2τtα∗​)=τ⟹tα∗​=2τ1​lnsα​−τsα​​

For sα​>τ, this crossing time exists and is smaller for larger sα​. For sα​<τ, the mode never reaches the threshold and remains permanently lazy.

This means that different modes can be in different regimes simultaneously: large-sα​ modes have crossed into the rich regime and are converging rapidly, while small-sα​ modes are still in the lazy phase (or may never leave it). The network interpolates between the two regimes mode by mode.

Connection to grokking: This lazy-to-rich transition provides a mechanism for grokking. During the lazy phase, the network fits the training data via kernel regression with the initial (misaligned) NTK — it memorizes. The test loss plateaus because the frozen kernel cannot capture the task structure. Later, as modes cross the threshold into the rich regime, feature learning kicks in: the NTK rotates to align with the task, and the test loss drops — generalization is achieved. The grokking delay is controlled by the time it takes the relevant modes to cross τ. Increasing the initialization scale σ or the width n increases τ, which extends the lazy phase and widens the grokking gap. This is the same mechanism identified by Kumar et al., Grokking as the Transition from Lazy to Rich Training Dynamics (arXiv:2310.06110). □

7. Stochastic implicit bias (bonus)

SGD introduces noise from mini-batching. A continuous model is the Langevin SDE:

dθt​=−∇L(θt​)dt+ηΣ(θt​)​dBt​

where Σ(θ) is the covariance of the stochastic gradient noise and η is the learning rate.

Exercise 7.1 (Boltzmann equilibrium). The probability density p(θ,t) of the parameters evolves according to the Fokker–Planck equation:

∂t​p=−∇⋅j,j=−∇L(θ)p(θ)−2η​∇⋅(Σ(θ)p(θ))

where j is the probability current. Assume: (i) stationarity ∂t​p∗=0, (ii) thermal equilibrium j=0, and (iii) isotropic noise Σ=σ2I. Show that the equilibrium distribution is the Boltzmann distribution:

p∗(θ)∝exp(−ησ22​L(θ))

Hint: Setting j=0 with Σ=σ2I gives ∇Lp+2ησ2​∇p=0. This is a first-order ODE for p in terms of L. Try the ansatz p∝e−βL and solve for β.

Solution

Setting j=0 (thermal equilibrium) with isotropic noise Σ=σ2I:

0=−∇L(θ)p∗(θ)−2ησ2​∇p∗(θ)

Rearranging:

p∗∇p∗​=−ησ22​∇L

The left-hand side is ∇lnp∗, so:

∇lnp∗(θ)=−ησ22​∇L(θ)

Integrating both sides:

lnp∗(θ)=−ησ22​L(θ)+constp∗(θ)∝exp(−ησ22​L(θ))​

This is the Boltzmann distribution with inverse temperature β=2/(ησ2). □

Exercise 7.2 (Temperature and flatness). The ratio ησ22​ plays the role of an inverse temperature β. Interpret what happens to the equilibrium distribution when:

  • η is very small (low temperature)
  • η is very large (high temperature)

Which regime favors flatter minima, and why might this be beneficial for generalization?

Solution

The effective temperature is T=ησ2/2.

Small η (low temperature, β→∞): The distribution concentrates sharply on the global minima of L. SGD converges to the lowest-loss minimizer without exploring.

Large η (high temperature, β→0): The distribution becomes nearly uniform over parameter space. SGD explores broadly and does not settle into any particular minimum.

Flat vs. sharp minima: At moderate temperature, the Boltzmann distribution assigns more probability mass to broad basins (flat minima) than to narrow ones. This is because a flat minimum occupies a larger volume of parameter space at any given loss level — the width of the basin acts as an entropic contribution. Flat minima tend to generalize better because small perturbations to the parameters (or slight distribution shift in the data) do not dramatically change the loss. Thus the implicit bias of SGD noise toward flat minima is beneficial for generalization. □

Exercise 7.3 (Anisotropic noise). In practice, SGD noise is not isotropic: Σ(θ) depends on both the loss landscape and the data. Without solving anything, explain qualitatively why anisotropic noise can introduce an implicit bias that goes beyond what the loss function L alone would select. Specifically, why might SGD preferentially escape sharp directions of the loss while remaining stable along flat directions?

Solution

When Σ(θ) is anisotropic, the noise strength varies by direction. The Fokker-Planck current becomes:

j=−∇Lp−2η​∇⋅(Σ(θ)p)

The second term introduces an Itô drift 2η​∇⋅Σ(θ) that depends on the spatial variation of the noise covariance. In directions where Σ has large eigenvalues (high noise), the effective diffusion is strong and the system escapes easily from sharp regions of the loss landscape. In directions where Σ has small eigenvalues (low noise), the system is more stable and tends to remain there.

This creates a direction-dependent regularizer: SGD preferentially pushes parameters out of sharp directions (high gradient variance → large noise eigenvalue → fast escape) while preserving parameters along flat directions (low gradient variance → small noise eigenvalue → stability). This goes beyond what the Boltzmann distribution on L alone would predict. In general, detailed balance j=0 may not hold for anisotropic, state-dependent noise, leading to persistent probability currents and non-equilibrium steady states that further modify the implicit bias. □
