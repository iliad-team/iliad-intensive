<LearningOutcomes>

**At the end of the day we have brought all students up to speed on:**

* Basic ML concepts
* LLM concepts
* Basic ML programming
* Basic Claude Code use

**Some participants who went in with more background got:**

* A deeper understanding of transformers architecture and other ML basics
* Experience renting out and setting up their own compute
* More advanced tools and setups to use Claude Code

</LearningOutcomes>

**Why**

I believe everyone who wants to work on AI safety should have a grasp of these basic concepts and skills. So we bring everyone to a level where it makes sense for them to do the rest of the Iliad intensive.

The more advanced skills should enable more technically minded participants to do good work that has a technical component.

**How**

We start with two parallel lectures: One lecture for participants with less ML background, where we go through ML and LLM basics, and go deeper into certain topics via hands on exercise notebooks. The second lesson is a practical exercise of renting out and setting up your own compute.

Lecture 2 is a series of exercises to use Claude Code to do small steps in an AI safety research repo, where each step should be done using a different Claude Code tool.

Lecture notes and materials for Lecture 1a self-contained within this repository: [https://github.com/wusche1/Illiad_ML_Engineering](https://github.com/wusche1/Illiad_ML_Engineering)

## Prerequisites

* You should have some rudimentary ability to code in python
* You should have heard of the ML basics before
* You should have your own Laptop
* You should have the Claude Code CLI running on your laptop
* You should know linear algebra, understand gradient descent

## Fast track

* Go over the slides of Lecture 1 a. Skip the section you are familiar with. Read the ones you are not familiar with. If you have time do one of the exercises
* Download the Claude Code CLI, and play around with it, to get familiar with its basic features

Intent:

* Give everyone the ML basics needed for the rest of the course
* Let people dive in deeper through exercises to give a more full understanding of the topics covered
* Give some hands on experience with common ML Libraries/methods

Content:

* Training loop — forward/backward pass, gradient descent, stochastic batching, optimizer role
* PyTorch tensors — basic operations, einops, batching & data loading, autograd/computational graph, devices & GPU
* Loss functions — classification losses, RL/human-rater losses, sparsity, train vs. test loss, over/underfitting
* Parameters, activations & hyperparameters — terminology + optimizers (momentum, RMSProp)
* Architectures — activation functions, universal approximation, over/underparameterization, symmetries in architecture design, CNNs, transformers, residual streams
* Hyperparameter optimization — sweeps, scaling laws
* LLM lifecycle - Pretraining, SFT fine tuning, RLHF, RLVRd
