# Speaker notes — C.2 Mechanistic Interpretability

Julian's own notes for this deck, copied verbatim from the source repo
(`wusche1/Illiad_Mech_Interp`, `lectures/`). Nothing here is built or published:
the site never reads this directory, and the two files below exist only so the
deck's narration is not stranded in a repo we no longer take the slides from.

They are rough drafts, typos and all. In them, `--` starts a new slide, `s:`
marks what he says out loud, and `@key` (or `@key/figure`) is a citation or a
captured figure from that paper.

Only two of the seven upstream notes files are here, because the rest are
redundant:

- `overview.md` — the day's planning outline. No counterpart in the deck.
- `05_fuzzy_interp.md` — the only section whose slides carry **no** `\note{}`
  blocks, so this draft is the only narration that section has.

For the other five sections, `slides.tex` already carries the finished version
of these notes as 108 beamer `\note{...}` blocks — the tidied text Julian
presents from. Those drafts stayed upstream rather than being copied in as a
second, rougher copy of narration this repo already has.

The `\note{}` blocks do not render: the deck sets no
`\setbeameroption{show notes}`, so the published PDF is slides only. To see them
while presenting, build with notes enabled or open the deck in a presenter tool
that reads them (`pdfpc --notes=right`).
